# STYLE-CHANGES：课件书面化改写说明

> 适用范围：`/workspace/feishu-lessons-formal/` 下 21 个课件文件（20 个正式课 + 1 篇参考阅读）。源文件：`/workspace/feishu-lessons-linked/`。改写依据：课程负责人反馈“课件的表述太过口语化，请用正式严谨的表述以及用词”。

## 1. 改写规则

- **删除口语化人称与语气**：删除“你/你们/咱们”，改为“学习者”“读者”或无主语句；删除“其实、说白了、换句话说（口语用法）、就完事、搞、弄、坑/踩坑、跑通、秒、狂”等口语词，以及句末语气词“吧、呢、啊、啦”和“……对吧？”式附加问。
- **删除感叹号与反问式引子**：全部感叹号改为句号；“为什么……？”“……怎么办？”等设问式引子改为陈述句（如“……的原因”“……的处理方法”）。保留的问号仅用于“问：……答：……”问答格式、练习题题干，以及明确列出的“需回答的问题”。
- **类比的处理**：随意的比喻改为直接的技术描述；确需保留且准确的类比，显式标注为“类比说明（仅用于辅助理解……）”（E2、E4）。
- **删除表情符号与带引号的俚语**：如参考阅读开头的“⚠️”改为“【注意】”；“欠账”“陪跑”“免费午餐”“两全其美”“卡死”“利器”等改为规范术语。
- **术语统一并在每课首次出现时定义**：键值缓存（KV Cache）、词元（token）、批次（batch）、内核（kernel）、预填充（Prefill）、解码（Decode）、分块预填充（chunked prefill）、首词元时延（TTFT）、词元间时延（ITL）、调度器（Scheduler）、张量并行（TP）、流水线并行（PP）、数据并行（DP）、专家并行（EP）。首次定义后，代码标识与英文缩写按原文保留。
- **因果与条件关系显式化**：以“由于……因此……”“若……则……”“当……时”等句式表达因果与条件；避免“很多、一堆、大概齐”等模糊量词，原文中已有的具体数值全部保留。
- **不新增技术主张、不删减内容**：所有数字、公式、代码、命令、表格、练习、警示与【待核】标记均予保留；改写中未增加新的技术结论。
- **标题**：措辞书面化，编号与层级结构不变；H1 标题保留，删除“（深度版）”字样；头部信息块（版本、导航、练习、源码标注）改为正式语体。
- **学习目标**：统一以“完成本课学习后，学习者应能够：”（参考阅读为“完成本文学习后，学习者应能够：”）开头，各条以“阐述/说明/计算/绘制/指出”等可检验的动词开头。
- **练习与自测**：练习使用明确的祈使句，并补充“验收标准”行（仅引用原文已给出的测试或预期结果，如“上述测试全部通过”、D1 的 scale=0.02 与 q=[25,−64,2,127]、E3 的 [2,4,1,1] 与 2.0 等）；自测题由“我能……”改为“能否……”。
- **原样保留的内容**：围栏代码块、行内代码、命令、路径、标识符、URL、图片引用行均与源文件逐字节一致（以占位符流程保证）；图注保留“图N：”前缀并仅作轻度书面化；页脚导航中的 URL 全部保留，“相关章节”中引用的本课章节名与引文同步更新为改写后的标题与语句。
- **篇幅控制**：每课字符数变化控制在 ±15% 以内（实际为 +2.8%～+7.0%）。
