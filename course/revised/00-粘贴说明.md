## 二、替换步骤（每篇重复）

1. **先备份**：在飞书中打开目标文档 → 右上角"…" → 创建副本（或查看历史版本确认可回滚）。浅版内容此后仍可从历史版本恢复。
2. **清空正文**：点击正文任意位置，`Ctrl/Cmd + A` 全选正文 → Delete。保留文档标题。
3. **复制深度版**：用文本编辑器（VS Code 等）打开对应 `.md`，全选复制。
4. **粘贴**：回到飞书正文，`Ctrl/Cmd + V`。飞书会把 Markdown 的标题、列表、表格、引用块、代码块自动转为对应格式；若出现"是否转换为 Markdown 格式"的提示，选择转换。
5. **处理重复标题**：文件第一行 `# ...` 会变成正文 H1，与文档标题重复时删掉正文中的这一行。
6. **插入配图**（每篇 2～3 张，共 45 张）：正文以 `![图N：…](images/<课号>/<课号>-figN.png)` 引用已渲染 PNG。粘贴 Markdown 后，若飞书未能自动载入图片，请从 `images/<课号>/` 将对应 PNG 插入相应位置。配图 mermaid 源文件位于 `diagrams-src/`，无需粘贴到飞书。
7. **公式与特殊符号**：正文中的 `×`、`≈`、`²`、`ᵀ` 等为 Unicode 字符，可直接显示；代码块中的公式保持原样即可。
8. **导航链接**：文首的 `[B2-Worker与Executor]` 等是文字占位，全部替换完成后统一改为飞书内部链接（@文档）。
9. **自测题**：`- [ ]` 应自动变为任务复选框；未转换时选中后设为「待办事项」格式。
